Entry for the make.fun bounty [One-Line Roast: The Gadget You Use Every Day](https://make.fun/c/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610): one line, at most 200 characters — a roast of a gadget or app the entrant uses every day.

## What it does

`main.ts` writes a single roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`):

> My smartwatch congratulates me for standing up, then silently judges me for sitting back down.

The line roasts the smartwatch as a judgmental coach: it cheers the one virtuous thing you did, then silently holds the relapse against you.

## Run

```sh
node main.ts
```
