A make.fun bounty entry: one original line roasting a gadget used every day.

The program (`main.ts`) writes a single roast line to `/output/entry.txt`:
the washing machine that plays a little victory song when it finishes, like it
deserves applause for one load. The line is guarded to the competition's gate
(1–200 characters, single line, valid UTF-8, no trailing newline) and verified
by a read-back check.
